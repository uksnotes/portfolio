# HI OFFICE — 로컬 실행 패키지

지금까지 구현한 3D 개인 오피스의 전체 소스와 실행용 빌드를 담았습니다.
**Python 3.10 이상 + Node.js 22.13 이상**을 설치한 뒤 ZIP을 완전히 압축 해제하고 실행하세요.
화면과 분석 로직은 기존 React / TypeScript를 유지하며, `app.py`는 로컬 Node 서버를 실행합니다.
**Python만으로 전체 코드를 재작성한 패키지는 아닙니다.** 실행에 pip / npm 설치는 필요하지 않습니다.

## 1. 실행

터미널에서 이 README와 app.py가 들어 있는 폴더로 이동합니다.

```bash
python app.py
```

`python main.py`도 같습니다. Mac에서 `python` 명령이 없다면 `python3 app.py`를 사용하세요.
브라우저가 자동으로 열리며, 직접 접속할 주소는 **http://127.0.0.1:8000** 입니다.

- 최초 아이디: `datascience_user1`
- 최초 비밀번호: `1234`
- 종료: 터미널에서 `Ctrl+C`
- 환경 검사: `python app.py --check`
- 포트가 겹치면: `python app.py --port 8001`
- 브라우저 자동 실행 끄기: `python app.py --no-browser`
- 비밀번호 변경: 서버를 종료한 다음 `python app.py --set-password`

Node가 없다면 https://nodejs.org 에서 설치하고 터미널을 다시 여세요.
Windows에서는 `start_windows.bat`으로도 실행할 수 있습니다.
인터넷 없이도 로그인, 3D 화면, 일정, 저장된 데이터 열람은 가능합니다.
새 시세·뉴스·부동산 조회와 AI 응답에는 인터넷이 필요합니다.

## 2. 포함 기능과 사용법

| 공간 | 포함된 기능 | 실행 조건 / 현재 범위 |
|---|---|---|
| 나의 오피스 | 3D 오피스, 캐릭터 이동, 공간 선택 | 방향키 / WASD와 화면 안내 사용, WebGL 지원 브라우저 필요 |
| 투자실 | 보유 종목·관심종목, 현재가 수동 조회 | 공개 페이지 조회, 사용자 API 키 불필요 |
| 분석실 | 코스피200 랭킹, 5년 인터랙티브 차트, 단기 지표와 매매 후보 가격 | ‘코스피200 랭킹 조회’ → 종목 클릭, 분석 중단 후 이어가기 |
| 보유 종목 분석 | 보유 종목 점수·가중치, 1년/5년 시세, CSV 등록 | 공개 시세 출처 차단 시 기존 캐시 유지 또는 CSV 이용 |
| 일정 보드 | 월간 일정, TO-DO, 완료 처리 | SQLite에 저장, 재시작 후 유지 |
| 뉴스룸 | 경제·사회·IT·세계·랭킹, 기사 핵심 요약 | 수동 새로고침, 기본 요약은 본문 기반 추출식 |
| AI 팀 오피스 | 역할별 분석가, 업무 진행·검토, GPT / Claude 모델 선택 | 개인 API 키 필요, 실제 제공 모델·계정 권한·크레딧에 따라 응답 가능 여부 결정 |
| 부동산 리서치 | 아파트 검색, 로얄동·층 후보, 실거래·매물 비교 | 공개 자료 범위에 따라 일부 항목은 미확인 / 수집 불가로 표시 |
| 메일 데스크 | 초안 저장, Gmail·Outlook·기본 메일 작성창 연결 | 사용자가 메일 서비스에서 최종 발송; 서버가 직접 보내는 SMTP 기능은 없음 |
| 알림 데스크 | 이메일 알림 초안 저장 | 현재 코드에는 예약 메일 자동 발송 작업이 연결되어 있지 않음 |

코스피200 가중치는 추세 30 / 모멘텀 25 / 거래량 20 / 가격 위치 15 / 변동성 10입니다.
완료된 일봉으로 비교하며, 매수 후보 구간·손절선·매도 목표는 조건부 시나리오입니다.
백테스트로 검증된 수익 확률이 아닙니다. 오래되거나 부족한 데이터는 보류합니다.
출처의 실제 구성 종목 수가 200과 다르면 확인된 수를 그대로 표시합니다.

AI 키는 **AI 팀 오피스 → API 키 설정**에서 본인이 입력합니다.
키는 SQLite에 암호화해서 저장합니다. 기존 대화나 웹 서비스의 API 키는 포함하지 않았습니다.
기존 모델 목록을 보존했으며, 모델 ID 변경이 필요하면 `source/lib/ai-team.ts`를 수정한 후 재빌드하세요.
원래 제공되지 않았던 직접 메일 발송·완전 자동 AI 실행·거래 주문 기능은 새로 추가하지 않았습니다.

## 3. 데이터 유지와 백업

첫 실행 시 다음 파일이 자동 생성됩니다.

| 파일 | 역할 |
|---|---|
| `data/office.sqlite3` | 일정·종목·초안·뉴스 캐시·분석 결과·AI 업무 등 |
| `data/settings.json` | 비밀번호 해시·암호화 키 |
| `data/office.sqlite3-wal`, `-shm` | 실행 중 SQLite가 사용할 수 있는 보조 파일 |

**종료 후 data 폴더 전체를 복사하면 백업할 수 있습니다.** 새 ZIP으로 교체할 때도 기존 data 폴더를 보존하세요.
DB만 옮기고 settings.json을 잃으면 저장된 API 키를 읽을 수 없습니다.
프로그램은 기존 DB나 설정을 자동 초기화하지 않습니다.
다른 폴더에 저장하려면 `python app.py --data-dir "D:/HI_OFFICE_DATA"`처럼 실행하세요.

이 ZIP은 코드 배포본입니다. **기존 웹 서비스의 일정·보유 종목·개인 데이터는 자동으로 이전되지 않습니다.**
로컬판에서 새로 입력한 데이터는 해당 PC에 저장되며, 웹 서비스와 자동 동기화하지 않습니다.
로컬판은 본인 PC의 단일 사용자 실행용이며, 회사 20명에게 공유하는 서버 배포 설정은 포함하지 않습니다.

## 4. 폴더와 코드

| 경로 | 내용 |
|---|---|
| `app.py`, `main.py` | Python 실행 진입점, 환경 확인, 비밀번호 변경 |
| `source/app/` | 기존 화면: 3D 오피스·분석실·뉴스·일정·AI 팀·부동산 |
| `source/app/api/[action]/route.ts` | 기존 API 요청 라우팅 |
| `source/lib/` | 시세·뉴스·아파트·분석 점수·AI 작업·인증 로직 |
| `source/components/ui/`, `source/hooks/` | 공통 UI 컴포넌트와 React 훅 |
| `source/drizzle/`, `source/db/` | DB 테이블 정의와 마이그레이션 |
| `source/public/`, `source/vendor/` | 아이콘·스타일·라이선스 |
| `source/tests/` | 기존 기능 회귀 테스트 |
| `source/build/`, `source/scripts/` | 기존 웹 서비스 빌드 관련 코드 참고본 |
| `runtime/environment.ts` | Cloudflare D1 인터페이스를 로컬 SQLite로 연결 |
| `runtime/server.ts` | 로컬 HTTP 서버, 단일 사용자 식별, 정적 파일 제공 |
| `runtime-dist/` | 사전 빌드한 API 서버 — 실행 시 npm 설치 불필요 |
| `web/main.tsx`, `index.html` | 로컬 웹 화면 진입점 |
| `static/` | 사전 빌드한 화면·3D·차트 파일 |
| `scripts/build.mjs` | 소스 수정 후 화면과 API 서버 재빌드 |
| `tests/test_local.py` | 실제 로컬 서버의 로그인·저장·재시작 유지 검증 |
| `docs/` | 코드 안내·검증 결과·배포 정보 |
| `data/` | 실행 후 생성되는 사용자 데이터 |

`source/`는 마지막 구현 소스 기준입니다. 서비스 식별 설정, Git 이력, 비밀키, 사용자 DB,
node_modules 및 호스팅 산출물은 원본 복사에서 제외했습니다.
`source/` 안에서 직접 npm start를 실행하지 말고 **최상위 app.py**로 실행하세요.

## 5. 코드 수정 후 재빌드

평소 실행에는 필요 없습니다. 개발할 때만 최상위 폴더에서 실행합니다.

```bash
npm install
npm run build
python app.py
```

- 화면 수정: `source/app/*.tsx`, `source/app/globals.css`
- 종목 점수·매매 후보: `source/lib/kospi-data.ts`
- 공개 시세 수집: `source/lib/kospi-ranking.ts`, `source/lib/market-history.ts`
- 뉴스 수집·요약: `source/lib/providers.ts`, `source/lib/news-summary.ts`
- AI 모델 목록: `source/lib/ai-team.ts`
- 로컬 실행 환경: `runtime/`, `app.py`

검증 명령: `python tests/test_local.py` — 임시 DB만 사용하며 외부 API·메일 발송을 호출하지 않습니다.
원본 Sites용 설정 파일은 로컬 실행에서 사용하지 않습니다. 로컬 실행과 원본 웹 서비스 배포는 별도입니다.

## 6. 오류 확인

| 증상 | 확인 방법 |
|---|---|
| 로그인 실패 | 기본 계정 확인, 변경한 비밀번호 사용, 5회 실패하면 10분 후 재시도 |
| Node.js를 찾지 못함 | Node 22.13+ 설치 후 터미널 재실행, `node --version` 확인 |
| 포트 사용 중 | `python app.py --port 8001` |
| 화면 파일 없음 | ZIP 전체 압축 해제, 또는 `npm install` → `npm run build` |
| 시세·뉴스·매물 조회 실패 | 인터넷/사내망 정책 확인, 원본 사이트 응답 확인; 임의 값으로 대체하지 않음 |
| AI 응답 없음 | 본인 키·크레딧·모델 접근 권한 확인 |
| 3D 화면 미표시 | 브라우저 하드웨어 가속 / WebGL 지원 확인 |
| 데이터가 다른 것처럼 보임 | 이전 실행과 같은 data 폴더를 쓰는지 확인 |

외부 원본 사이트가 형식이나 접근 정책을 변경하면 수집 코드를 업데이트해야 할 수 있습니다.
