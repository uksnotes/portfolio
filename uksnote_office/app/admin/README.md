# admin — 사용자 관리

`/admin`은 `office_users.role = 'admin'`인 계정만 사용할 수 있습니다. 가입은 승인 없이 바로 이용되며, 관리자는 필요할 때만 개입합니다.

| 탭 | 하는 일 | 데이터 |
| --- | --- | --- |
| 사용자 | 차단과 차단 해제(즉시 로그인 종료), 관리자 지정과 해제, **비밀번호 재설정** | `office_users` |
| 기능 사용 | 기능별 방문과 실행 횟수, 사용자별로 많이 쓴 기능 (7일, 30일, 90일, 전체) | `feature_usage` |
| 사용자 로그 | 가입, 로그인, 실패, 차단, 비밀번호 재설정과 변경 기록 (이메일과 이벤트 필터, 100건씩) | `user_logs` |

## 비밀번호 재설정

비밀번호는 Supabase Auth에 해시로만 저장되어 관리자도 원래 값을 볼 수 없습니다. 대신 임시 비밀번호를 발급합니다.

1. **비밀번호 재설정**을 누르면 임시 비밀번호(예: `Xk7m-Pq3r-Tz9w`)가 한 번만 표시됩니다. 어디에도 저장되지 않습니다.
2. 그 사용자의 기존 로그인은 바로 끊기고, 목록에 `임시 비밀번호` 표시가 붙습니다.
3. 사용자가 임시 비밀번호로 로그인하면 새 비밀번호를 정하는 화면만 열리고, 바꾼 뒤에 오피스를 쓸 수 있습니다.

사용자는 왼쪽 메뉴의 열쇠 아이콘으로 언제든 직접 비밀번호를 바꿀 수 있습니다.

API는 `app/api/[action]/route.ts`의 `admin-users`, `admin-user`, `admin-password`, `admin-usage`, `admin-logs`이고, 처리 로직은 `lib/accounts.ts`와 `lib/usage.ts`에 있습니다.
